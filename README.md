# UK PadelFinder

A UK-focused padel club directory web app built with Next.js, Convex, ShadCN UI, and Tailwind CSS.

## Features

- **Browse & Search Clubs**: Filter by city, rating, and online booking availability
- **Club Detail Pages**: Full club information with contact forms
- **City Landing Pages**: SEO-optimized pages for each city
- **Analytics Tracking**: Track views, booking clicks, and leads
- **Lead Generation**: Contact forms that save to the database

## Tech Stack

- **Frontend**: Next.js 14 (App Router), TypeScript, ShadCN UI, DaisyUI, Tailwind CSS
- **Backend**: Convex (real-time database, queries, mutations)
- **Fonts**: Geist Sans & Mono

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn
- Convex account (free at [convex.dev](https://convex.dev))

### Installation

1. **Clone and install dependencies**:
   ```bash
   npm install
   ```

2. **Initialize Convex**:
   ```bash
   npx convex dev
   ```
   This will:
   - Prompt you to log in to Convex
   - Create a new project (or select existing)
   - Generate types in `convex/_generated/`
   - Create `.env.local` with your Convex URL

3. **Keep Convex running** in one terminal, then in another terminal:

4. **Import club data from CSV**:
   ```bash
   npm run import:csv
   ```
   This imports UK clubs from `data/fpc-results-v1.csv`

5. **Start the development server**:
   ```bash
   npm run dev
   ```

6. **Open** [http://localhost:3000](http://localhost:3000)

## Environment Variables

Create `.env.local` (auto-generated by Convex):

```env
NEXT_PUBLIC_CONVEX_URL=https://your-deployment.convex.cloud
CONVEX_URL=https://your-deployment.convex.cloud
```

## Deployment

### Spaceship / Vercel

1. Connect your repository
2. Set environment variables:
   - `NEXT_PUBLIC_CONVEX_URL` - Your Convex deployment URL
3. Deploy!

### Convex Production

```bash
npx convex deploy
```

## Data Model

### Clubs Table
- name, categories, address, city, postcode
- phone, website, maps_url, booking_url
- lat, lng, rating, rating_count
- opening_hours_raw, image_url
- slug (unique), status, is_featured, plan

### Leads Table
- club_id, name, email, message, created_at

### Analytics Events Table
- club_id, type (view/booking_click/lead_submitted), created_at
